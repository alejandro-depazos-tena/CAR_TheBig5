# Práctica 1 · Simulación térmica paralela con OpenMP

Estructura de trabajo:

```text
Laboratorio1/
├── docs/                 # Enunciado y documentación de la práctica
├── include/              # Cabeceras compartidas, por ejemplo crono.h
├── src/
│   ├── ejercicio1/       # Código fuente del ejercicio 1
│   ├── ejercicio2/       # Código fuente del ejercicio 2
│   ├── ejercicio3/       # Código fuente y scripts del ejercicio 3
│   ├── ejercicio4/       # Código fuente del ejercicio 4
│   └── ejercicio5/       # Código fuente del ejercicio 5
├── resultados/
│   ├── ejercicio1/       # Salidas y datos del ejercicio 1
│   ├── ejercicio2/       # Salidas y datos del ejercicio 2
│   ├── ejercicio3/       # Salidas, gráficas y datos del ejercicio 3
│   ├── ejercicio4/       # Salidas y datos del ejercicio 4
│   └── ejercicio5/       # Salidas y datos del ejercicio 5
└── entrega/              # Material final que se entregará
```

Compila y ejecuta los programas desde la raíz del repositorio para que las
rutas relativas a `include/` y `resultados/` sean consistentes.
